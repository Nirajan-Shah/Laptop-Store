# Laptop-Store
This is a text based project where the authorized seller can sell laptops to the user or order from the manufacturers. The staff can view the database, add an entry, remove an entry, view the details of one or more laptops at once and generate bell when ordering or selling.

Run Main.py to start the user interface. <br/>

Features of this project: <br/>

- Generate bill for when both selling and ordering laptops.
- Add an entry to the database
- Remove an entry from the database
- View the database
- View the details of one or more than one laptops at once.
